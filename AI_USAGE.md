# Использование генеративного ИИ

## Консультация по frontend

- Участник: M1
- Задача: уточнить организацию пользовательского интерфейса клиентской части Volt.
- Использование ИИ: получены предложения по структуре frontend-компонентов и организации интерфейса на React.
- В проект вошло: выбранный и адаптированный командой вариант структуры интерфейса для основных сценариев продукта.
- Проверка человеком: проверено соответствие предложенного варианта существующим сценариям, ролям пользователей и границам продукта; неподходящие предложения не использовались.
- Связанный результат: клиентская часть проекта; используемый frontend-стек указан в `PROJECT.md`.
