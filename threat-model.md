# Модель угроз

## Модель продукта

React-клиент в браузере отправляет запросы к ASP.NET Core Web API. Через API пользователь регистрируется и входит в систему, создаёт рабочие пространства и секреты, просматривает и изменяет разрешённые секреты, а также выдаёт и отзывает права доступа. API обращается к PostgreSQL, где хранятся учётные записи, рабочие пространства, секреты, права доступа и журнал действий. Браузер не подключается к базе данных напрямую.

**Что уже существует:** согласованный паспорт проекта и требования безопасности `SR-*`.

**Что пока планируется:** React-клиент, ASP.NET Core Web API, PostgreSQL и операции из минимального функционального ядра.

**Существенные допущения:** идентификаторы секретов, рабочих пространств и пользователей приходят из браузера и не подтверждают права пользователя; право на действие определяет сервер. К базе данных обращается только серверное приложение.

## Границы доверия

| Граница | Что пересекает | Почему требуется проверка |
| --- | --- | --- |
| Браузер пользователя — серверный API | Данные регистрации и входа, идентификаторы объектов, команды создания, просмотра, изменения и удаления секретов, а также выдачи и отзыва доступа | Пользователь может изменить любой запрос из браузера: подставить чужой идентификатор или вызвать операцию, которой нет в интерфейсе для его роли. |
| Серверный API — PostgreSQL | Запросы на чтение и изменение учётных записей, секретов, прав и журнала | База хранит значимые данные; доступ к ней должен выполняться только сервером в рамках проверенной операции пользователя. |

## Значимые объекты и свойства

Значимые объекты и последствия их нарушения описаны в [разделе 5 паспорта проекта](PROJECT.md#5-значимые-данные-и-другие-объекты). Для модели особенно важны значения секретов, права доступа к ним и записи журнала.

## Приоритетный набор

`T-01`, `T-02`, `T-03`, `T-04` и `T-05` входят в приоритетный набор. Они возникают на основной границе браузер — API, реалистичны для веб-приложения и могут привести к раскрытию или изменению рабочих секретов. `T-06` и `T-07` имеют средний приоритет, потому что требуют дополнительного доступа к базе данных или журналу.
